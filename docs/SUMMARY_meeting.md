## 2. v1 — 합성 불꽃(플랫) 검출

**파이프라인**
- **모델**: YOLOv8s(COCO 사전학습)를 우리 데이터로 파인튜닝. 결론이 한 모델의 우연이 아닌지 보려고 **YOLOv11s로도 똑같이 한 번 더 학습해 교차검증**.
- **학습 데이터 만드는 법**: 급식실 배경 사진에 **불꽃을 합성해 얹은 이미지 = "불 있음(양성)"**, 불을 안 얹은 배경·헷갈리기 쉬운 무화재 장면 = **"불 없음(음성)"**으로 라벨링. 이 이미지들로 80번 반복 학습(EPOCHS 80).
- **노이즈 강건성 실험**: 이미지에 노이즈(흐림·저조도·압축 등)를 점점 세게 얹으며 **검출이 얼마나 무너지는지** 보고, 그 노이즈를 **학습에 넣으면 회복되는지** 확인. 통계 신뢰 위해 조건을 바꿔가며 **총 30번 학습**(2개 모델 × 3개 구성 × 5개 seed).
- **검증 3가지**: ① 처음 보는 합성 이미지에서 잘 잡나(합성 test) ② **불꽃만 지웠을 때 검출이 사라지나** — 모델이 배경이 아니라 진짜 '불'을 보는지 확인(ablation) ③ **진짜 화재 영상(realfire)에서도 되나** = 실제 전이 시험.

**한계**
- **실제 화재 인식률이 낮음** — 진짜 화재 영상에서 불을 잡아낸 비율 **약 31%**(recall 0.31 ≈ 나머지 69%는 놓침). *'하한'* = 경계·연기 가림을 엄격히 쳐서 실제론 이보다 조금 높을 수 있음.
- **배경 보고 찍는 건 아님(ablation 통과)**: 불꽃을 지우면 검출이 0.81→0.005로 사라짐 → 모델은 진짜 '불'을 본다. → 그렇다면 낮은 이유 = **학습에 쓴 합성 불꽃이 종류가 적고(4종) 실제 불과 덜 닮음**(거대불꽃 hisomu 0.04).
- 노이즈 학습으로 강건성을 키워도 **실제 화재 인식은 안 좋아짐**. 학습에 없던 실제 장면에선 **사람을 불로 오인**(헛불)하기도.

## 3. v2 — 실사 아틀라스 + 발광 합성

**파이프라인**
- **모델**: 동일 YOLOv8s (v1 하네스 재사용).
- **변경(단일변수)**: 불꽃 = **실사 아틀라스 390장 + 발광 합성**(스크린 블렌딩 + 코어 블룸 + 엣지 페더 + 조명 스필). 조건 **C0(=v1 플랫) vs C3(=풀 v2)** A/B.
- **학습**: 10모델(C0·C3 × 5seed), EPOCHS 60.
- **검증**: realfire **영상 단위 ± 군집 CI**, ablation.

**한계 (음성 — 가설 기각)**
- **C3 ≈ C0** (realfire 0.237 vs 0.223, Δ −0.014) → **불꽃의 현실성·다양성은 병목이 아니었다.**
- ablation 통과(모델이 불꽃을 0.94로 제대로 씀) → 음성은 "모델 망가짐"이 아니라 **"진짜 전이 실패"**.
- realfire 5영상뿐 → CI 큼(작은 효과는 배제 못 함).

## 4. v3 — DINOv3 표현(백본) 프로브

**파이프라인**
- **모델**: **DINOv3**(실제 이미지 사전학습 ViT, base·large) — **학습 0, 고정특징만**.
- **방법**: 표현만 바꾸는 단일변수 프로브(분류). DINOv3 vs YOLO(합성)·YOLO(COCO)·ResNet50를 **고정특징 + 선형/kNN**으로 realfire 전이(AUROC) 비교.
- **의도**: 무거운 탐지기 재구축 전, "표현 교체가 전이를 고치나"만 싸게 선검증.

**한계 (음성에 가까움)**
- DINOv3 신호는 **실재하나 작음**(kNN ~0.65로 유일하게 우연 초과 — 진짜 신호), **Δ +0.04~0.05로 기준(+0.10) 미달**.
- **모델 3.5배(base→large) 키워도 realfire +0.016뿐 = 스케일 무반응** → **표현 축도 전이 병목의 레버가 아님.**
- (프로브 = 분류 proxy · realfire N=5 → 공식 판정은 보류, 실질 결론은 위와 같음)

## 5. 최종 정리

**핵심 문제(v1)는 세 시도를 관통해 그대로다:** 합성은 잘 배우나 **실제 화재 전이가 약하다.**

세 번의 시도로 **병목 후보 2개를 제거**했다:
- ❌ **불꽃 현실성·다양성** (v2로 기각)
- ❌ **모델 표현/백본** (v3 DINOv3로 기각 — 진짜지만 작고 비확장)

**근본 원인 진단:** 학습 라벨이 **합성뿐**이라, 어떤 모델(YOLO·DINOv3)도 **합성에 없는 실제 화재 단서를 배울 수 없다.** → **병목은 모델이 아니라 데이터/도메인.**

**다음 방향(권장):** **씬·도메인갭 · temporal(시간축).** (불꽃도 표현도 아니므로 남은 축.)

**[자세히(병목 제거 논리 도식) →](DETAIL.md#conclusion)**

**정직한 경계:**
- realfire 영상 5개 → 통계적 검정력 낮음(방향 지표).
- 급식실 **실화재** 자료는 없음 — synth(급식실×합성불)와 realfire(실제불×비급식실)를 **삼각측량**하는 것이지 직접 증명 아님.
- v3 프로브는 분류 proxy(최종 탐지 성능 아님).
