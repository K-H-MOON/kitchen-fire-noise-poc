## 0. 목적 — 두 실험

1. **합성 화재 인식**: 실제 주방 조리 사진에 불꽃 사진을 합성한 화재 이미지를
   모델에 학습시키고, 화재를 인식하는지 판별한다.
2. **노이즈 강건성**: 그 화재 이미지에 노이즈를 얹었을 때 모델이 여전히 화재로
   인식하는지, 인식률이 어디서부터 떨어지는지 판별하고, 떨어지면 극복 방안을 찾는다.

## 2. 분할 — 사이트 단위 (data leakage 방지)

`scripts/assign_split.py` → `scripts/split.json`. 프레임 추출 전에 확정.

| 세트 | 사이트 | 영상 | 조리종류 | CCTV |
|------|------|:---:|------|:---:|
| train | 금정초·남일고·논현중·부산체고·숭곡중·영동중·울산현대차·원촌중·진선여고 | 19 | 국탕4·볶음4·튀김11 | 0 |
| val | 로봇고·인화여중 | 6 | 볶음3·튀김3 | 0 |
| test | 개원중·내곡중 | 3 | 국탕1·튀김2 | 2 |

- **왜 사이트 단위** — 같은 주방 프레임이 train/test 에 겹치면 배경·조명을 외운다.
  최종 합성 이미지가 달라 보여도 누수다.
- **왜 개원중이 test** — 유일한 CCTV. 실제 배포 환경에 가장 가깝다. 한 번도 안 본
  주방에서의 일반화를 잰다.
- **조리 종류 균형은 강제하지 않음** — 국탕·볶음 사이트가 각 3곳뿐이라 세 세트에
  다 넣기 어렵다. 사이트 분리가 1순위. 대신 val 에 국탕 없음, test 에 볶음 없음을
  숨기지 않고, 평가를 **조리 종류별(per-dish)로 쪼개** 보고한다.

### 누수 통제 규칙 (불가침)
1. 재료(주방·불꽃 소재)를 **먼저** 분할하고, 그다음 각 세트 안에서 합성한다.
   먼저 합성해서 랜덤 8:2 로 나누지 않는다.
2. 노이즈·증강은 **분할이 끝난 뒤** 각 세트 내부에서만 적용한다. 같은 깨끗한
   이미지가 노이즈만 다르게 양쪽에 들어가지 않게 한다.
3. 불꽃 소재도 train/test 풀을 분리한다 (같은 불꽃 스프라이트가 양쪽에 없게).

## 3. 프레임 샘플링 규칙

`scripts/colab_extract_frames.py`. 배경(불 없는) 프레임만 만든다.

- 추출 레이트 **1 fps** (조리는 느려 초당 1장이면 충분)
- 중복 제거 — 직전 채택본과 유사도 **> 0.90** 이면 버림 (냄비만 젓는 정지 구간 제거)
- 사이트당 상한 **400장** (한 주방이 데이터를 독식 못 하게). 상한이지 할당량이 아님.
- 영상당 하위 상한 = ceil(400 / 그 사이트 영상 수) ('full' 영상 독식 방지)
- 실제 수율은 추출 후 표로 확인하고 상한을 조정할 수 있다.

## 4. 합성 (다음 단계)

- 불꽃 스프라이트를 배경 프레임 위에 합성. **알파 마스크가 곧 정답 박스** →
  검출 라벨 자동 생성, 수작업 주석 0.
- **합성 아티팩트 지름길 방지**가 최우선:
  - Poisson blending + 색·밝기 매칭 + 주변 glow/반사광
  - 네거티브에도 '붙여넣기'를 포함 (불꽃 아닌 밝은 물체·김도 같은 방식으로 합성)
    → "붙인 것 ≠ 무조건 불" 을 학습시킴
  - 학습 전 **Grad-CAM/EigenCAM 으로 모델이 불꽃을 보는지** 확인. 경계선을 보고
    있으면 노이즈 실험의 저하 곡선이 '틀린 이유'로 나온다.
- 실제 불꽃 프레임 소량(≈100장, 손 라벨)을 **정직성 검증셋**으로 따로 둔다.

## 5. 노이즈 실험

- **두 종류 모두**:
  - 화질: 가우시안·JPEG압축·블러·저조도 (ImageNet-C severity 5단계)
  - 의미적: 김·수증기·조명 반사·유니폼을 합성 주입
- **Phase A** — 깨끗한 합성으로만 학습 → 노이즈 강도 0→5 올리며 저하 곡선. 종류별
  분리 곡선. 어디서 mAP 가 무너지는지 임계점 파악.
- **Phase B** — 노이즈를 학습 증강으로 투입해 재학습 → 같은 곡선을 다시 그림.
  곡선이 위로 오르면 극복 성공(정량 입증). 의미적 방해물은 하드 네거티브로 보강.

## 6. 모델·지표

- 사전학습은 **일반(COCO 등)** 에서 시작. 이전 프로젝트의 급식실-학습 가중치는 안 씀.
