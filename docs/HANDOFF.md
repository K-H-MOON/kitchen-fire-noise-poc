# 공개용 작업 요약 — 생성형 #6 이후

## 현재 결론

생성형 화재 이미지로 사전학습한 뒤 실제 화재 데이터로 파인튜닝하는 #6 커리큘럼은
완료했다. 고정 신뢰도 임계값 0.25에서 급식실 오탐률은 기준 모델 `2g`의 0.260에서
`2gencurr`의 0.492로 증가했고, 장면 단위 재현율은 0.813에서 0.822로 큰 차이가 없었다.
따라서 생성형 커리큘럼이 일반화 격차를 해결했다는 결론은 채택하지 않는다.

`sc14` 장면은 0.175에서 0.250으로 올랐지만 표본이 작고 학습 시드가 하나뿐이므로,
약한 탐색 신호로만 기록한다. 서로 다른 재현율에서 고정 임계값 수치를 비교했으므로,
재현율을 맞춘 임계값 비교(confidence sweep)를 수행하기 전까지 오탐 악화의 크기를
최종 수치로 확정하지 않는다.

## 다음 선택지

1. **신뢰도 임계값 비교** — 기준 모델과 생성형 커리큘럼 모델을 같은 장면 재현율에서
   비교해 오탐 차이를 확정한다.
2. **생성형 자료와 조리 하드 네거티브 결합** — 생성형이 보인 약한 장면 신호가
   조리 오탐을 줄이는 학습과 함께 유지되는지 별도 사전 등록 뒤 검증한다.
3. **범용화 평가** — 안 본 급식실의 높은 이벤트 단위 헛경보가 남은 핵심 문제다.
   주방별 보정이 현재의 현실적인 운영 경로이며, 단일 범용 모델은 아직 미해결이다.
