**합성 방식(C0 컷아웃 vs C3 발광)만 바꾸고 나머지(배경·분할·장수·seed·배치)는 완전 고정**하는

## 2. 게이트 판정 (PREREGISTER_v2 §7)

| 결과 | 뜻 | 다음 |
|---|---|---|
| **C3 ≫ C0** (CI 비겹침·delta>0) | 현실성 개선이 전이를 올림 | → Phase 2 |
| **C3 ≈ C0** | 병목은 불꽃이 아님 (값진 음성) | → 방향 전환 (배경·temporal·백본 DINOv3 등) |
| C3 ≪ C0 | 현실성이 전이를 낮춤 (예상 밖) | → 원인 재점검 |
| delta 있으나 CI 겹침 | 유의성 약함 | → realfire·seed 확대 검토 |

**동시 조건:** `성공` = 검출↑ + real_fp 악화 없음 + 가드 유지. 성공을 전제하지 않는다.

## 4. 학습 데이터 준비 상태

학습 입력 = `synth_C0`·`synth_C3` (Drive `fire_frames/`). 두 데이터셋은 **같은 배경·분할·장수·seed**,
불꽃 소스+합성 방식만 다르다.

### 4.1 구성 (C0·C3 동일)

| split | 배경 | 양성 | 하드네거 | 음성 | 불꽃 풀 |
|---|---:|---:|---:|---:|---|
| train | 2,278 | 1,385 | 335 | 558 | C0 v1매트 109 · C3 아틀라스 348 |
| val | 294 | 171 | 40 | 83 | (train 풀) |
| test | 309 | 173 | 49 | 87 | C0 56 · C3 42 (held-out) |

- 소재: flamelib **390장·8소스**(RGBA 실알파), train/test 소스 분할 348/42(§5.6).
- 배경: 실제 급식실 튀김솥 사진, 사이트 단위 분할(v1 확립).

### 4.2 확인 방법과 상태

| 항목 | 확인 방법 | 상태 |
|---|---|---|
| 장수 무결성 | 검산 — 이미지 = 라벨 = 배경 수 | ✅ 통과 |
| 단일변수 | **C0·C3 카운트 완전 동일** (역할 rng 분리) | ✅ 확인 |
| 무신호 라벨 차단 | 가시성 게이트 — 박스 평균\|Δ\| ≥ 바닥, 미달 시 재배치 | ✅ 중앙 ~17·fallback ~1% |
| 자동 박스 정확도 | 알파 bbox 결정적 로직 + QC 시트 육안 | ✅ 표본(~12장) |
| 소재 ↔ 검증 분리 | 0-overlap 대조 시트 (스톡화염 ↔ 튀김유화재) | ✅ 통과(육안·출처) |
| 발광 개선 | Phase 0 육안 (C0 컷아웃 vs C3 발광) | ✅ 통과 |

### 4.3 "양질"의 경계 (정직)

- **표본 확인이지 전수 아님:** 박스는 QC 시트 ~12장 + 결정적 로직으로 확인 — ~1,385장 전수를
  눈으로 보진 않았다(자동 생성이라 체계적 오류 가능성은 낮음).
- **의도된 한계(결함 아님):**
  - **배치가 제약된 무작위** — 불꽃이 가끔 조리면이 아닌 곳(솥 테두리·팔)에 떠 있음(위치 증강).
  - **C3 일부 반투명** — 게이트가 무신호는 걷어냈으나 옅은 것 잔존(실제 불도 반투명).
  - **본질적으로 합성** — 2D 합성의 천장이 있음. 그 간극 자체가 Phase 1 이 재는 대상.
- **데이터는 최종:** EPOCHS 는 학습 파라미터지 데이터가 아니라, 재생성 불필요.

## 5. 런타임 검증 상태 (실행으로만 확인 가능한 것)

- **S0·S1·S3·Phase 0** — 실제 Colab 실행·검산으로 확인됨.
- **Phase 1 하네스**(`v2_train`·`v2_eval`·`v2_probe`) — 작성 + 구문검사 + 라인 감사 완료.
  런타임 검증은 프로브(train 경로)·본 평가(eval 경로) 첫 실행이 최종 확인. 감사에서 발견한
  버그(판정 분기·GPU 메모리·csv 파싱 방어)는 수정됨.
- **필요 자료:** 학습 = `synth_C0`·`synth_C3`(있음). realfire 평가 = `smoke_frames`의 유류화재
  영상 5개(v1 realfire 경로).
