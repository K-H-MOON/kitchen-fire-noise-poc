# 미팅 브리프 — v3 Phase 0 (DINOv3 표현 프로브) 중간 보고 (2026-08-22)

v2 음성(병목 = 불꽃 아님)을 받아 **표현/백본 축**을 프로브로 검증. 진짜 DINOv3(vitb16) 실행 결과:
**DINOv3 표현엔 도메인-강건 불 신호가 "조금" 있음(DINOv2엔 없던 것 — kNN 0.66) · 그러나 YOLO 대비 우위 작음(Δ +0.037, GO 기준 +0.10 미달) · 공식 판정 보류(sanity 0.896<0.90, 근소) · N=5 검정력 부족.**
→ 이 증거만으론 DINOv3 탐지기 착수 근거 부족. 다음 = 더 큰 DINOv3(vitl16)로 신호 확대 여부 확인 or 씬/temporal 피벗.

## 어디서 왔나 (v1→v2)
- **v1**: 합성 불꽃 학습 → 실제 화재 전이 약함(realfire ~0.31, 하한). 병목 가설 = 불꽃이 플랫·협소.
- **v2**: 실사 아틀라스 + 발광 합성(C0 vs C3 단일변수 A/B). **결과 음성 — C3 ≈ C0**(realfire C0 0.237 vs C3 0.223, delta −0.014). ablation은 **모델이 합성 안에선 불꽃을 제대로 씀**(flame 0.94 ≫ bg 0.00) 확정. → **병목은 불꽃 현실성이 아니라 그 바깥**(표현·씬·temporal).
- 팀 제안 triage: 남은 실질 레버 = **DINOv3(표현 축)**.

## v3 Phase 0 프로브 설계 (비용 방어)
전면 탐지기 재구축 전, **핵심 질문만 싸게**: "실제-프리트레인 파운데이션 ViT(DINOv3) 표현이 합성→실제 전이가 YOLO보다 나은가?"
→ **백본 고정(학습 0) + 선형/kNN 프로브**. 단일변수 = 표현. 주지표 realfire **AUROC**(영상단위·군집 CI).

## 결과 (진짜 DINOv3-vitb16 · 고정특징 448 + 패치 mean/max)

| 백본 (고정특징) | synth-val AUROC | realfire AUROC (영상단위±CI) | **kNN**(무학습) |
|---|---|---|---|
| **DINOv3-vitb16** | 0.896 | **0.660 ± 0.348** | **0.660** |
| YOLO(합성 v8_C0_s1) | 0.996 | 0.623 ± 0.516 | 0.562 |
| YOLO(COCO) | 0.643 | 0.606 ± 0.312 | 0.599 |
| ResNet50(ImageNet) | 0.815 | 0.553 ± 0.477 | 0.507 |

ΔAUROC(DINOv3 − YOLO_synth) = **+0.037**, per-video 2/4 DINOv3 우세, CI 겹침.

## 어떻게 읽나 — "진짜지만 작은 신호, GO엔 미달"
1. **DINOv3만 raw 특징에 불 신호 있음(핵심)**: kNN(학습 없는 순수 표현) 0.660 — 4백본 중 유일하게 우연(0.5)을 뚜렷이 넘고 선형과 일치. → **표현에 도메인-강건 불 신호가 실재.** (참고: DINOv2는 kNN 0.500 = 가짜였음)
2. **그러나 우위는 작음**: Δ +0.037 → 사전등록 **GO(+0.10) 미달**, |Δ|<0.05라 NO-GO 밴드.
3. **불확실**: CI 거대(±0.35, chance 관통), per-video 2/4 → YOLO와 통계적 구분 불가.
4. **절대 전이도 중약(0.66)** — 실제 불로 잘 넘어간다고 못 함.

## 판정 (사전등록 v3 §6)
**공식: 판정 보류** — synth-val sanity(≥0.90) 미달 **DINOv3 0.896(근소)**. 규율상 기준 사후 변경 없음(단 0.896은 "추출 깨짐" 아님 — 게이트 목적은 충족).
**실질: 표현 축은 "진짜지만 작은" 신호 → 이 증거만으론 DINOv3 탐지기 착수 근거 부족.** DINOv2와 달리 신호가 가짜는 아니라(kNN), 완전 기각도 아님.

## 남은 블로커
- **검정력**: realfire 영상 5개 → CI가 커서 +0.037이 실재인지 노이즈인지 확정 불가.
- **모델 규모 미탐색**: 기저(vitb16)에서 신호가 처음 보임 → 더 큰 DINOv3(vitl16 등)에서 커지는지 미확인.

## 다음 (결정 대상)
- **더 큰 DINOv3(vitl16)** (권장·싸다): 기저에서 진짜 신호가 처음 보였으니 스케일로 커지는지 확인. 커지면→표현 축 유력, 그대로면→표현 축 사실상 닫힘. env 하나(`DINOV3_HF`)만 바꿔 재실행.
- **realfire 확장(②)**: N↑ → CI↓로 +0.037이 실재인지 판별. **이제 후보(DINOv3)에 edge가 있어 확장이 정당화됨**(전엔 우위 자체가 없어 실익 낮았음).
- **씬/temporal 피벗**: 표현 신호가 작으니, 병목이 씬·도메인·시간축일 가능성 병행 검토.
