# 미팅 브리프 — v3 Phase 0 (DINOv3 표현 프로브) 중간 보고 (2026-08-22)

## 한 줄
v2 음성(병목 = 불꽃 아님)을 받아 **표현/백본 축**을 프로브로 검증. 진짜 DINOv3 **base·large 두 스케일** 실행:
**표현에 도메인-강건 불 신호는 실재(kNN ~0.65, DINOv2엔 없던 것) · 그러나 작고(Δ +0.04~0.05, GO +0.10 미달) 모델 3.5배 키워도 안 커짐(+0.016) · 공식 판정 보류(sanity<0.90) · N=5.**
→ **표현 축은 전이의 병목을 여는 레버가 아니다**(완전 기각은 아닌 진짜-작은 신호). 다음 = 씬·도메인·temporal 피벗 권장.

## 어디서 왔나 (v1→v2)
- **v1**: 합성 불꽃 학습 → 실제 화재 전이 약함(realfire ~0.31, 하한). 병목 가설 = 불꽃이 플랫·협소.
- **v2**: 실사 아틀라스 + 발광 합성(C0 vs C3 단일변수 A/B). **결과 음성 — C3 ≈ C0**(realfire C0 0.237 vs C3 0.223, delta −0.014). ablation은 **모델이 합성 안에선 불꽃을 제대로 씀**(flame 0.94 ≫ bg 0.00) 확정. → **병목은 불꽃 현실성이 아니라 그 바깥**(표현·씬·temporal).
- 팀 제안 triage: 남은 실질 레버 = **DINOv3(표현 축)**.

## v3 Phase 0 프로브 설계 (비용 방어)
전면 탐지기 재구축 전, **핵심 질문만 싸게**: "실제-프리트레인 파운데이션 ViT(DINOv3) 표현이 합성→실제 전이가 YOLO보다 나은가?"
→ **백본 고정(학습 0) + 선형/kNN 프로브**. 단일변수 = 표현. 주지표 realfire **AUROC**(영상단위·군집 CI).

## 어떻게 읽나 — "진짜 신호지만 레버 아님"
1. **신호는 실재(기각 아님)**: DINOv3는 base·large 모두 **kNN ~0.65로 우연(0.5)을 뚜렷이 넘음** — 4백본 중 유일. → 표현에 도메인-강건 불 신호가 있음. (DINOv2는 kNN 0.500 = 가짜)
2. **그러나 작고 안 자람(핵심)**: Δ +0.04~0.05로 **GO(+0.10) 미달**, **모델 3.5배 키워도 +0.016** → 이 기울기론 초거대 모델로도 GO 못 넘음. **스케일이 답이 아님.**
3. **불확실**: CI 큼(large ±0.29로 다소 개선), per-video 3/4 → 통계적으론 여전히 YOLO와 구분 경계.
4. **절대 전이 중약(0.68)** — 실제 불로 잘 넘어간다고 못 함.

## 판정 (사전등록 v3 §6)
**공식: 판정 보류** — synth-val sanity(≥0.90) 미달(base 0.896·large 0.882). 규율상 기준 사후 변경 없음(단 추출 깨짐 아님 — 게이트 목적 충족).
**실질: 표현 축은 "진짜지만 작고 비확장" 신호 → 전이 병목을 여는 레버가 아니다.** DINOv2와 달리 가짜는 아니나, 두 스케일에서 GO 근처도 못 감 → **DINOv3 탐지기 착수 근거 약함.**

## 남은 블로커
- **검정력**: realfire 영상 5개 → CI 큼(large에서 다소 개선). Δ 0.05가 실재라도 GO 미달이라 판단 안 뒤집힘.

## 다음 (결정 대상)
- **씬·도메인·temporal 피벗** (권장): v2(불꽃 아님) + v3(표현도 레버 아님·스케일 무반응) → 병목은 **씬/도메인갭·시간축**일 가능성이 가장 큼. 영상별 편차가 백본차보다 크다는 신호와도 정합.
- **표현 축은 종료 권장**: base·large 모두 GO 근처 못 감 + 비확장 → 더 큰 DINOv3 투자 실익 낮음. (신호가 진짜라 완전 폐기는 아니고, 다른 축이 안 풀릴 때 재방문 여지)
- **realfire 확장(②)**: 필요 시 Δ 확정용이나, GO 미달이라 판단을 바꾸진 않음 → 우선순위 낮음.
