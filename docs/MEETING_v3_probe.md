# 미팅 브리프 — v3 Phase 0 (DINOv3 표현 프로브) 중간 보고 (2026-08-22)

## 한 줄
v2 음성(병목 = 불꽃 아님)을 받아 **표현/백본 축**을 프로브로 시작했다. 현재:
**DINOv2(대리)로는 표현 전이 우위 없음 · 진짜 DINOv3는 Meta 승인 대기 · 판정은 공식 보류(검정 게이트 미달) · N=5 검정력 부족.**

## 어디서 왔나 (v1→v2)
- **v1**: 합성 불꽃 학습 → 실제 화재 전이 약함(realfire ~0.31, 하한). 병목 가설 = 불꽃이 플랫·협소.
- **v2**: 실사 아틀라스 + 발광 합성(C0 vs C3 단일변수 A/B). **결과 음성 — C3 ≈ C0**(realfire C0 0.237 vs C3 0.223, delta −0.014). ablation은 **모델이 합성 안에선 불꽃을 제대로 씀**(flame 0.94 ≫ bg 0.00) 확정. → **병목은 불꽃 현실성이 아니라 그 바깥**(표현·씬·temporal).
- 팀 제안 triage: 남은 실질 레버 = **DINOv3(표현 축)**.

## v3 Phase 0 프로브 설계 (비용 방어)
전면 탐지기 재구축 전, **핵심 질문만 싸게**: "실제-프리트레인 파운데이션 ViT(DINOv3) 표현이 합성→실제 전이가 YOLO보다 나은가?"
→ **백본 고정(학습 0) + 선형/kNN 프로브**. 단일변수 = 표현. 주지표 realfire **AUROC**(영상단위·군집 CI).

## 결과 (현재 · DINOv2 대리로 측정)

| 백본 (고정특징) | synth-val AUROC | realfire AUROC (영상단위±CI) | 풀링 AUROC | kNN |
|---|---|---|---|---|
| DINO(**dinov2**-vitb14) | 0.851 | **0.691 ± 0.409** | 0.628 | 0.532 |
| YOLO(합성 v8_C0_s1) | 0.996 | 0.623 ± 0.516 | 0.657 | 0.562 |
| YOLO(COCO) | 0.643 | 0.606 ± 0.312 | 0.647 | 0.599 |
| ResNet50(ImageNet) | 0.815 | 0.553 ± 0.477 | 0.660 | 0.507 |

ΔAUROC(DINO − YOLO_synth) = **+0.067**, per-video 3/4 DINO 우세 — 그러나 아래 이유로 **실재 우위로 못 읽음**.

## 어떻게 읽나 — "표현 우위 없음 (잠정)"
1. **순위 불안정**: DINO는 영상단위 평균 1위인데 **풀링 AUROC로는 꼴찌(0.628)**. 지표만 바꿔도 1위↔꼴찌 → 차이가 노이즈.
2. **kNN 전부 0.5~0.6**(우연 근처) — 학습 없는 순수 표현 거리로는 아무도 불을 못 가림.
3. **CI 거대**(±0.31~0.52, chance 관통) → 백본 간 통계적 구분 불가.
4. **영상별 편차가 지배적**(DINO 영상별 0.82·0.99·0.49·0.46) — 백본 차이보다 훨씬 큼.

## 두 블로커 (정직)
- **DINOv3 접근**: 라이선스 게이트 — 동의·요청은 제출됐으나 **Meta 수동 승인 대기**. 승인 전엔 못 돌림. → **진짜 DINOv3는 아직 미검증**(위 수치는 DINOv2 대리).
- **검정력**: realfire 영상 5개 → CI가 커서 어느 방향도 확정 불가.

## 판정 (사전등록 v3 §6)
**공식: 판정 보류** — synth-val sanity(≥0.90) 미달(DINO 0.851). 규율상 기준 사후 변경 없음.
**실질: 표현 축 우위 근거 약함 (잠정)** — 게이트를 제쳐도 순위 불안정·kNN 우연·CI 겹침으로 결론 동일. 단 **진짜 DINOv3 미검증**이라 팀 제안을 문자 그대로 닫지는 못함.

## 다음 (결정 대상)
- **DINOv3 승인 오면**: 토큰 넣고 즉시 재실행(몇 분, 스크립트 준비 완료).
- **realfire 확장(②, Roboflow)**: 승인과 무관하게 **N↑ → CI↓**로 검정력 확보 — 현재/미래 결론 모두를 굳힘. (배찬우 님 제안이 검정력 병목 해소로 정당화됨)
- **씬/temporal 진단**: 영상별 편차가 백본차보다 크다는 신호 → 병목이 표현이 아닐 가능성.
